  ★  STEP-BY-STEP SETUP  ★
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  STEP 1 – START XAMPP
  ─────────────────────
  a. Open XAMPP Control Panel
  b. Click [Start] next to Apache
  c. Click [Start] next to MySQL
  d. Both should show green "Running" status

  STEP 2 – CREATE THE DATABASE
  ──────────────────────────────
  a. Open your browser → go to: http://localhost/phpmyadmin
  b. Click the "SQL" tab at the top
  c. Open the file:  sql/schema.sql  (from this project folder)
  d. Copy ALL the text from schema.sql
  e. Paste it into the phpMyAdmin SQL box
  f. Click [Go]
  g. You should see:  "student_performance_db" appear in the left sidebar
  h. Verify these 5 tables were created:
       ✓ users
       ✓ students
       ✓ courses
       ✓ enrollments
       ✓ grades

  STEP 3 – OPEN PROJECT IN NETBEANS
  ────────────────────────────────────
  a. Open NetBeans IDE
  b. Go to: File → Open Project
  c. Navigate to and select the "StudentPerformanceTracker" folder
     (the folder containing build.xml and nbproject/)
  d. Click [Open Project]
  e. The project will appear in the Projects panel on the left

  STEP 4 – ADD THE MYSQL JAR LIBRARY
  ────────────────────────────────────
  a. Place your mysql-connector-java-8.x.jar file inside the /lib/ folder
  b. In NetBeans: Right-click on the project name → Properties
  c. Click "Libraries" in the left sidebar
  d. Click [Add JAR/Folder]
  e. Navigate to the /lib/ folder → select the mysql-connector jar → [Open]
  f. Click [OK] to close Properties

  STEP 5 – VERIFY DATABASE CONNECTION (optional)
  ────────────────────────────────────────────────
  Open:  src/db/DatabaseConnection.java
  Confirm these values match your setup:

      HOST     = "localhost"
      PORT     = "3306"
      DATABASE = "student_performance_db"
      USERNAME = "root"
      PASSWORD = ""       ← empty string for XAMPP default

  If your MySQL has a password, put it inside the quotes.

  STEP 6 – RUN THE APPLICATION
  ──────────────────────────────
  a. Right-click on  src/Main.java
  b. Click "Run File"   OR press  Shift + F6
  c. The Login screen will open
  d. Log in with any credentials listed above

  ─────────────────────────────────────────────────────────────

  ─────────────────────────────────────────────────────────────

  TABLE: grades  (one grade per enrollment)
  ─────────────────────────────────────────────────────────────
  id | enrollment_id → enrollments.id | grade_value | grade_letter
     | semester | academic_year

  PROBLEM: "Cannot connect to database" popup on startup
  FIX:     Make sure XAMPP MySQL is running (green in Control Panel)
           Check DatabaseConnection.java – host/port/username/password

  PROBLEM: ClassNotFoundException for MySQL driver
  FIX:     You forgot to add the mysql-connector-java-8.x.jar to Libraries
           Right-click Project → Properties → Libraries → Add JAR/Folder

  PROBLEM: "Table doesn't exist" SQL error
  FIX:     Re-run schema.sql in phpMyAdmin. Make sure you see
           "student_performance_db" in the left sidebar of phpMyAdmin.

  PROBLEM: Application won't compile
  FIX:     Go to Tools → Java Platforms → must be JDK 11 or JDK 17
           Not JDK 8 (project uses Java 11 features)

  PROBLEM: Login fails even with correct password
  FIX:     Database may not have sample data. Re-run schema.sql fully.
           The INSERT statements at the bottom of schema.sql add the users.

  PROBLEM: Student signup – "email already exists" error
  FIX:     That student email is already in the database (from sample data).
           Use a different email, or log in with the existing student account.
